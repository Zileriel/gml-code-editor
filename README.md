# GM Lite

**GM Lite** is a lightweight, modern **IDE for GameMaker** built with **Electron** and **React**.  
It provides a fast and streamlined code-editing experience designed specifically for GameMaker developers, offering features that go beyond the default editor to improve productivity and workflow.

---

## ✨ Features

- **Lightweight IDE** – Optimized for speed and simplicity.
- **Scope History** – Keep track of your navigation history within code scopes.
- **Declaration Tracker** – Quickly jump to variable, function, and object declarations.
- **Multi-File Search** – Efficiently search across your entire project.
- **Shortcut & Keybinds Panel** – Access a curated list of useful shortcuts tailored for GameMaker.
- **Modern Editor** – Syntax highlighting, IntelliSense-like hints, and editor themes.
- **Cross-Platform** – Runs on Windows, Linux, and macOS via Electron.

## 🚀 Installation

### Prerequisites
- [Node.js](https://nodejs.org/) (LTS recommended)  
- [Git](https://git-scm.com/)  
- Yarn or npm package manager  

### Steps
```bash
# Clone the repository
git clone https://github.com/WhispererX/gm-lite.git
cd gm-lite

# Install dependencies
npm install
# or
yarn install

# Start development mode
npm run dev

# Build the production app
npm run build
```

The built application will be available in the `dist/` folder.

---

## 🔧 Usage

- Open GM Lite and load your **GameMaker project folder**.
- Use the **multi-file search** to quickly locate resources.
- Navigate code easily with the **scope history and declaration tracker**.
- Customize **themes and keybinds** to match your workflow.
